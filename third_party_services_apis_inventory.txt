====================================================================
1) QUICKNODE (BLOCKCHAIN RPC PROVIDER)
====================================================================
Used for: crypto deposit detection, balance reads, and ETH/USDT withdrawal broadcasts.
Where: backend/services/blockchain_service.py

Base URLs from env:
- QUICKNODE_ETH_URL (Ethereum JSON-RPC)
- QUICKNODE_BTC_URL (Bitcoin JSON-RPC)

RPC methods currently used:
Ethereum side:
- eth_chainId
- eth_getTransactionCount
- eth_sendRawTransaction
- eth_getTransactionReceipt
- eth_blockNumber
- eth_getBalance
- eth_call
- eth_estimateGas
- eth_getBlockByNumber
- eth_getLogs
- eth_maxPriorityFeePerGas
- eth_gasPrice

Bitcoin side:
- scantxoutset

Notes:
- Provider mode: BLOCKCHAIN_PROVIDER=quicknode
- ETH/USDT withdrawals require TREASURY_ETH_PRIVATE_KEY
- USDT uses USDT_ERC20_CONTRACT

2) BINANCE SPOT API
====================================================================
Used for: market prices, market metadata, hedger account, and market order execution.
Where:
- backend/services/hedger_service.py
- backend/server.py
- backend/options/services/settlement.py

Base URLs:
- https://api.binance.com (mainnet)
- https://testnet.binance.vision (testnet)

REST endpoints currently used:
- GET  /api/v3/ticker/price
- GET  /api/v3/exchangeInfo
- GET  /api/v3/account         (signed)
- POST /api/v3/order           (signed; MARKET orders)
- GET  /api/v3/ticker/24hr
- GET  /api/v3/klines
- GET  /api/v3/depth
- GET  /api/v3/trades

Notes:
- Options settlement also fetches Binance ticker price.
- Hedger can run testnet-first depending on BINANCE_TESTNET.
